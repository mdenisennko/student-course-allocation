# Распределение студентов по учебным курсам

## О проекте

Учебный проект, выполненный в рамках курса «Машинное обучение 1» факультета компьютерных наук НИУ ВШЭ.

Проект посвящен анализу и автоматизации процесса распределения студентов по учебным курсам.

## Задача

Необходимо распределить студентов по курсам с учетом:

- их предпочтений;
- рейтинга успеваемости;
- ограничений на размер учебных групп.

## Что сделано

В рамках проекта:

- подготовила и исследовала данные;
- провела Exploratory Data Analysis;
- проанализировала предпочтения студентов;
- работала с рейтингом успеваемости;
- учитывала ограничения на вместимость курсов;
- автоматизировала часть процесса распределения с помощью Python.

## Этапы работы

1. Загрузка данных
2. Проверка качества данных
3. Exploratory Data Analysis
4. Анализ предпочтений студентов
5. Учет академического рейтинга
6. Учет ограничений по вместимости
7. Формирование распределения

## Стек

**Python · pandas · Matplotlib · Seaborn**

## Навыки

- работа с табличными данными;
- EDA;
- преобразование данных;
- алгоритмическое решение прикладной задачи;
- автоматизация обработки данных;
- визуализация.
